
# Startup CRM
> Plataforma CRM - Enfocada en la automatización y gestión de comunicaciones vía WhatsApp e Email, incluyendo métricas y segmentación de usuarios.


## Funcionalidades

**Gestión de Contactos:** Configuración de etiquetas, vistas y filtros guardados.

**Comunicaciones:** Integración de canales de comunicación como Email y Whatsapp, manteniendo un registro de la actividad.

**Automatización:** Envío de emails con templates y recordatorios automáticos.,

**Analítica:** Panel de métricas y exportación de datos a formatos CSV y PDF.


## Stack Tecnológico

 **Backend:** Python, Django, Django REST Framework.
 
**Base de Datos:** SQLite3.

 **Integraciones:** WhatsApp Cloud API (Meta), API SMTP.
 
 **Frontend:** React, Tailwindcss.
